# 📌 Project Overview

Football Predictor Hub is an AI-powered football analytics platform that leverages Machine Learning and Deep Learning models to predict league winners, match outcomes, and player performance (goals and assists). The application provides an intuitive Streamlit interface for football enthusiasts, analysts, and researchers to generate real-time predictions using trained models.
